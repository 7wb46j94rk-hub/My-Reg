# My Reg

Project for **The Veterans Cottage**.

Started: 2026-11-01

## Visitor Register (`index.html`)
A sign-in / sign-out register for visitors. Double-click `index.html` to open it in a web browser.

- **Sign in** – visitor's name, who they're visiting, reason, optional phone and car registration.
- **Sign out / Who's here** – everyone currently in the building (can be used as a fire roll-call).
- **Register book** – past visits by date, searchable, with **Download for Excel** and **Print**.

Visit records are kept in the browser on the device you use it on — they are **not** saved in this folder or on GitHub. Download a copy for Excel regularly as a backup.
